# Komentář k zákonu č. 90/2016 Sb., o posuzování shody stanovených výrobků při jejich dodávání na trh

Otevřený komentář k zákonu o posuzování shody stanovených výrobků — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; hospodářské subjekty, posuzování shody, prohlášení o shodě a označení CE, oznámené subjekty a státní zkušebnictví, zvláštní ustanovení pro jednotlivé skupiny výrobků, dozor nad trhem, ochranná opatření a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2016-00090_2025-07-01`.
